# 2026-2DGP Item Mode

[2026-2DGP](https://github.com/sanu1227/2026-2DGP)의 `Labs/LEC15_Game_Framework`와 기존 작업 내용을 기반으로 만든 별도 프로젝트입니다. 첫 커밋은 아이템 모드를 추가하기 전의 코드와 이미지를 보존합니다.

## 실행

Windows와 Python이 필요합니다. 한글 표시는 Windows의 맑은 고딕을 사용합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

`main.py`를 실행하면 로고가 2초 표시된 뒤 타이틀로 전환됩니다.

## 조작

| 모드 | 키 | 동작 |
| --- | --- | --- |
| 타이틀 | Space | 플레이 시작 |
| 타이틀 | ESC | 종료 |
| 플레이 | 좌우 방향키 | 이동 |
| 플레이·아이템 | Space | 선택한 공 발사. 잠든 상태라면 먼저 일어남 |
| 플레이 | ESC | 타이틀 복귀 |
| 플레이 | P | 일시정지 |
| 정지 | P | 기존 플레이로 복귀 |
| 플레이 | I | 아이템 모드 열기 |
| 아이템 | 0 | 공 없음 선택: 이후 공 발사 안 함 |
| 아이템 | 1 | 기본 공 선택: 21×21 |
| 아이템 | 2 | 큰 공 선택: 41×41 |
| 아이템 | I 또는 ESC | 선택을 유지하고 아이템 모드 닫기 |

아이템 모드에서도 이동, 애니메이션, 이미 발사된 공의 움직임은 계속됩니다. 숫자 키는 공 종류를 선택하고, Space가 발사를 담당합니다. `0`은 이미 발사된 공을 지우지 않습니다. 새 플레이를 시작하면 기본 공으로 초기화됩니다.

## 구조

- `PauseMode`: 플레이 위에 쌓이며 게임 업데이트를 멈춥니다.
- `ItemMode`: 플레이 위에 쌓이지만 `game_world.update()`를 계속 호출합니다.
- `Boy.ball_size`: 0, 21, 41로 발사할 공을 선택합니다.
- `Ball`: 크기에 맞는 기존 이미지를 사용합니다.

사용자 요청에 따라 자동 검증, 테스트, 실행 확인은 수행하지 않았습니다.
